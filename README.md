# Electricity

電気設備工事の図面作成（CADWe'll Tfas 14 E）を自動化するためのツール群です。

## tfastool

Tfas 図面ファイル（`.tfs`）を Python から直接読み書きする実験的なツールです。
ファイル形式は公開されていないため、実ファイルの解析結果に基づいています。
追加ライブラリは不要です（Python 3.10 以上）。

```bash
python -m tfastool parts 図面.tfs
```

図面に配置されている Tfas 部材（部材コード・名称・個数）を一覧表示します。`--csv` で CSV 出力になります。

```bash
python -m tfastool list 図面.tfs
```

部材を 1 個ずつ、配置座標（mm）つきで表示します。

```bash
python -m tfastool place 入力.tfs 出力.tfs --sheet 2 --code E0A10S290008 --at 9000,8500 --at 9900,8500
```

指定した部材を指定座標に追加した図面を別名で書き出します。同じシートに配置済みの同じ部材を
ひな形として複製するため、その部材が 1 個も無いシートには追加できません。向きはひな形と同じです。

```bash
python -m tfastool wire 入力.tfs 出力.tfs --sheet 2 --between 86564,86570
```

2 つの部材（`list` で表示される ID）を配線で結びます。水平または垂直に並んでいれば直線、
斜めの位置関係なら L 字（既定は縦→横、`--corner hv` で横→縦）になります。
レイヤ・線種・条数は、同じシートにある既存の配線と同じになります。
配線の端は器具記号の円の中心になります（天井付けの器具では配置基準点、壁付けのコンセントや
スイッチでは基準点からずれた円の中心）。配線が他の器具記号と重なる部分を隠す処理は未対応です。

```bash
python -m tfastool rooms 図面.tfs --sheet 3
```

建築図のシートから、部屋名の文字ごとに部屋の範囲と中心（壁と壁の中心）を求めて表示します。
壁として扱うレイヤは、名前に「仕上」「開口」「建具」を含むものが既定で、`--wall-layers 65,66,71` のように
番号で指定もできます（番号は `python -m tfastool layers 図面.tfs` で確認）。

```bash
python -m tfastool roomlight 入力.tfs 出力.tfs --arch-sheet 3 --sheet 2 --code E0C40S290003 --room "洋室(3)"
```

指定した部屋の中心に部材を配置します。

```bash
python -m tfastool info 図面.tfs
```

ファイル内部の構造の概要を表示します。

```bash
python -m tfastool rewrite 入力.tfs 出力.tfs
```

読み込んだ内容をそのまま書き直します（書き込み処理の検証用）。

### 現状

- 読み込み：ファイル全体を解析でき、部材コードと個数を取り出せます。
- 書き込み：内容を変えずに書き直すと元ファイルと完全に一致します。
  圧縮し直したファイル、文字を書き換えたファイルは Tfas 14 E で正常に開けることを確認済みです。
- 部材の追加：既存の部材を複製して配置できます。追加した部材が Tfas 14 E 上で
  部材として選択されることを確認済みです（拾い集計での確認は未実施）。
- 配線の追加：水平・垂直の区間でできた経路の配線を追加できます（`tfastool/wiring.py`）。
  直線の配線は Tfas 14 E 上で配線として認識されることを確認済みです。
  折れ曲がる配線は、生成した図形が Tfas 自身の描いた既存配線と一致することをデータ上で確認済みで、
  折れ曲がる配線も Tfas 14 E 上で問題なく開けることを確認済みです。
  スイッチ・コンセントへの接続位置は、サンプル図面の既存配線と全件一致することをデータ上で確認済みです。
- 部屋の検出（`tfastool/rooms.py`）：試作段階です。四角い部屋では実際の照明位置とほぼ一致しますが、
  L 字形の部屋、収納が張り出した部屋、引出線つきの部屋名では正しい範囲になりません。
- ヘッダ内の 20 バイト（位置 0x40）の用途は不明です。
