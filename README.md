# Electricity

電気設備工事の図面作成（CADWe'll Tfas 14 E）を自動化するためのツール群です。

## tfastool

Tfas 図面ファイル（`.tfs`）を Python から直接読み書きする実験的なツールです。
ファイル形式は公開されていないため、実ファイルの解析結果に基づいています。
追加ライブラリは不要です（Python 3.10 以上）。

```bash
python -m tfastool parts 図面.tfs
```

図面に配置されている Tfas 部材（部材コード・名称・個数）を一覧表示します。`--csv` で CSV 出力になります。

```bash
python -m tfastool list 図面.tfs
```

部材を 1 個ずつ、配置座標（mm）つきで表示します。

```bash
python -m tfastool place 入力.tfs 出力.tfs --sheet 2 --code E0A10S290008 --at 9000,8500 --at 9900,8500
```

指定した部材を指定座標に追加した図面を別名で書き出します。同じシートに配置済みの同じ部材を
ひな形として複製するため、その部材が 1 個も無いシートには追加できません。向きはひな形と同じです。

```bash
python -m tfastool wire 入力.tfs 出力.tfs --sheet 2 --between 86564,86570
```

2 つの部材（`list` で表示される ID）を直線の配線で結びます。部材どうしが水平または垂直に
並んでいる必要があります。レイヤ・線種・条数は、同じシートにある既存の配線と同じになります。

```bash
python -m tfastool info 図面.tfs
```

ファイル内部の構造の概要を表示します。

```bash
python -m tfastool rewrite 入力.tfs 出力.tfs
```

読み込んだ内容をそのまま書き直します（書き込み処理の検証用）。

### 現状

- 読み込み：ファイル全体を解析でき、部材コードと個数を取り出せます。
- 書き込み：内容を変えずに書き直すと元ファイルと完全に一致します。
  圧縮し直したファイル、文字を書き換えたファイルは Tfas 14 E で正常に開けることを確認済みです。
- 部材の追加：既存の部材を複製して配置できます。追加した部材が Tfas 14 E 上で
  部材として選択されることを確認済みです（拾い集計での確認は未実施）。
- 配線の追加：水平・垂直の直線 1 本で 2 部材を結ぶ配線を追加できます（`tfastool/wiring.py`）。
  Tfas 上での動作は検証中です。折れ曲がる経路は未対応です。
- ヘッダ内の 20 バイト（位置 0x40）の用途は不明です。
